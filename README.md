# Personal Page

My personal site, hosted with GitHub Pages.

## How to update

Everything lives in `index.html`. Edit the placeholder text (anything in `[brackets]`), then:

```sh
git add -A && git commit -m "Update content" && git push
```

The site redeploys automatically within a minute or two.

Moving things between sections: when you finish something in **Now**, cut its `<li>` and paste it at the top of the matching list in **Previously**. When you start something from **Next**, move its `<li>` up into **Now**. Remember to bump the "Last updated" line in the footer.
